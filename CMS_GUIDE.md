# Decap CMS

Адрес редактора: `/admin/`.

## Первый запуск

1. Откройте `/admin/` и войдите через GitHub.
2. В разделе «Новини та оголошення» создавайте новости и объявления. Заполните заголовок, дату и категорию, затем соберите материал из текстовых блоков, заголовков, фотографий, галерей, цитат, списков и ссылок.
3. В разделе «Сторінки сайту» редактируйте существующие страницы визуальной панелью или готовыми блоками. Исходный Markdown и вставка кода отключены.
4. В разделе «Бібліотека» меняйте заголовки и тексты её разделов, фотографии, документы и слайды портфолио. Добавляйте и переставляйте элементы кнопками редактора.
5. В разделе «Документи та посилання» добавляйте файл в репозиторий или ссылку на внешний документ.
6. В разделе «Налаштування сайту» меняйте контакты, ссылки на соцсети, описание главной страницы и подпись подвала.

Редактор показывает визуальные кнопки форматирования, а не исходный Markdown. Структура страницы собирается готовыми блоками; в текстовом редакторе отключены исходный режим и вставка кодовых блоков.

Каждое сохранение создаёт коммит в GitHub. GitHub Actions запускает `build.py`, обновляет папку `dist`, а Cloudflare Pages публикует результат. Обычно это занимает несколько минут.

## Перенос на аккаунт колледжа

После переноса репозитория измените `repo`, `site_domain`, `base_url` и `auth_endpoint` в `src/admin/config.yml`. Для нового домена обновите callback URL GitHub OAuth App и секреты `GITHUB_CLIENT_ID` и `GITHUB_CLIENT_SECRET` в Cloudflare Worker/Pages.

OAuth-приложение даёт доступ только к репозиторию, указанному в настройках. Для публичного репозитория используется минимальный scope `public_repo user:email`; для приватного задайте `GITHUB_OAUTH_SCOPE=repo user:email`.
