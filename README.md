# ФКБАД — сайт коледжу

Завершений статичний фронтенд українською мовою. Джерело матеріалів: `../fkbad_migrator/fkbad_export_lean/`.

```powershell
python -m pip install -r requirements.txt
python build.py
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Відкрити http://127.0.0.1:4173/. Для розміщення на окремому домені опублікувати вміст `dist/` як статичний сайт із підтримкою `index.html` у вкладених каталогах та `404.html` для невідомих адрес. Node.js потрібен лише для необов’язкової перевірки синтаксису JavaScript.

У `build.py` містяться перетворення даних, спільні компоненти та шаблони. Стилі й клієнтські взаємодії — у `src/`. Зображення беруться лише з використаних матеріалів експорту, оптимізуються у WebP та копіюються без WordPress/Elementor CSS або JavaScript. Статті та документи доступні через звичайні посилання; JavaScript потрібен для пошуку, фільтрів і мобільного меню.

Дані відповідають наданому експорту; новини й документи оновлюються повторним запуском генератора після оновлення експорту. CMS, особистий кабінет і надсилання заяв через власний сервер до цього проєкту не входять. Офіційні документи, розклад і зовнішні ресурси відкриваються у відповідних сервісах.
