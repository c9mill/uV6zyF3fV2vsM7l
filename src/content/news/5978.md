<div class="editorial-flow"><div class="editorial-section"><p>    1 жовтня в нашому коледжі відбулися “Уроки мужності” — зустріч із  заступником командира загону з психологічної підтримки персоналу Житомирського військового інституту імені С.П. Корольова Кузьменком Євгенієм.<br/>    Фахівець з вищою психологічною та педагогічною освітою має свій нестандартний метод викладання, що дало змогу донести студентам основні меседжі щодо зорового способу життя, такі як відсутність шкідливих звичок, загартування, заняття спортом. Лектор використовував інтерактивні вправи та тематичні вірші, наводив приклади із власного життєвого досвіду, що здобувачам освіти було цікаво.<br/>    Також Євгеній Миколайович наголосив студентам на важливості читання книг, адже всі успішні люди читають книги.<br/>    Захід відбувся в бібліотеці коледжу, були присутні студенти груп першого курсу, а саме: 42а, 133, 16од.<br/>    Життя  та здоров’я наших здобувачів освіти — найвагоміше для нас. Якісна профілактика та просвіта сприятимуть формуванню здорового й свідомого студентського колективу.</p></div><div class="editorial-gallery photo-grid"><div class="editorial-photo"><img alt="Уроки мужності для студентів першого курсу" decoding="async" loading="lazy" src="/assets/4d9d5cabffbd3996.webp"/></div><div class="editorial-photo"><img alt="Уроки мужності для студентів першого курсу" decoding="async" loading="lazy" src="/assets/50ca7952d1635a90.webp"/></div><div class="editorial-photo"><img alt="Уроки мужності для студентів першого курсу" decoding="async" loading="lazy" src="/assets/ce5c737983eeb03b.webp"/></div><div class="editorial-photo"><img alt="Уроки мужності для студентів першого курсу" decoding="async" loading="lazy" src="/assets/e2a83a208de1f4fa.webp"/></div><div class="editorial-photo"><img alt="Уроки мужності для студентів першого курсу" decoding="async" loading="lazy" src="/assets/af509c4ee0afedb9.webp"/></div><div class="editorial-photo"><img alt="Уроки мужності для студентів першого курсу" decoding="async" loading="lazy" src="/assets/9220c31d7ac88149.webp"/></div><div class="editorial-photo"><img alt="Уроки мужності для студентів першого курсу" decoding="async" loading="lazy" src="/assets/21dc7d7a1a4f4b4a.webp"/></div></div></div>
